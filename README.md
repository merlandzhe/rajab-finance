# HESAP

Telegram Mini App для оформления рассрочек и CRM предпринимателей.

## Исходный код

Актуальный код приложения находится в `src/`, конфигурация Next.js — в корне репозитория. Продакшен: https://hesap-mini-app.vercel.app

- Next.js 16, React 19, TypeScript, Supabase, Vercel.
- `npm ci` — установка зависимостей.
- `npm run build` — сборка, включая восстановление двух статических DejaVu-шрифтов из сохранённого исходного архива.
- `npm run dev` — локальный сервер.

## База данных

`supabase/migrations/` содержит SQL-миграции, восстановленные из истории **уже применённых** миграций действующего Supabase-проекта. Не применяйте их повторно к рабочей базе. Для новых изменений создавайте следующую миграцию, проверяйте отдельно и сохраняйте вместе с изменениями кода.

## Развёртывание

Проект Vercel `rajab-finance-mini` привязан к репозиторию `merlandzhe/rajab-finance`. Основная ветка — `main`. После проверки изменений обновляйте `main`; Vercel собирает Git-коммиты. Секреты хранятся только в переменных окружения Vercel/Supabase, никогда в Git.

Временный архив `rajab-source.tar.gz` сохранён только для извлечения двух бинарных шрифтов при сборке. Основной код хранится в обычных исходных файлах, не в архиве.
