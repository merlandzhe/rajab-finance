# Схема и доступ

Все бизнес-таблицы используют UUID и tenant_id. Составные внешние ключи `(tenant_id, id)` не позволяют связать документы, договоры, клиентов и кассы разных организаций. `organizations.id` является корнем tenant; профили Auth глобальны. `subscription_plans` — общий справочник тарифов платформы, не клиентские данные.

| Таблица | Назначение |
|---|---|
| organizations | Изолированные организации |
| organization_members | Проверяемое членство, роли, отключение доступа |
| profiles | Имя пользователя, флаг администратора платформы |
| customers | Клиенты без паспортных сведений, необязательная привязка к Auth |
| applications | Запрос конкретного товара, предварительные данные и окончательное согласование |
| suppliers, products | Основа нормализованных справочников; в MVP товар/поставщик сохраняются снимком в сделке |
| purchases | Неизменяемое приобретение, цена, дата, собственность, документ |
| contracts | Фиксированная цена, номер, даты, статусы передачи/закрытия |
| contract_items | Неизменяемый предмет договора |
| contract_versions | Неизменяемый JSON-снимок согласованных условий и версия шаблона |
| payment_schedules | График, включая взнос как sequence=0 |
| payments | Append-only поступления и отдельные отрицательные отмены |
| payment_allocations | FIFO-распределение поступлений и обратные записи при отмене |
| cash_accounts | Кассы |
| cash_transactions | Append-only приход, расход, переводы, операции договора |
| documents | Приватные файлы закупки, SHA-256, MIME, размер |
| document_templates | Версионированные демонстрационные шаблоны |
| notifications | Транзакционная очередь уведомлений с дедупликацией и lease |
| audit_logs | Append-only история команд, авторов и статусов |
| organization_settings | Неизменяемые версии правил наценок |
| subscription_plans, subscriptions | Основа SaaS-подписок, без биллинга |
| operations | Idempotency keys, параметры и результат операции; клиентам SELECT запрещён |
| private.rate_limits | Общие серверные лимиты, не открывается через Data API |

## Денежные типы и ограничения

Стоимость и прибыль до 1 млрд ₽ каждая, BIGINT в копейках. Наценка в basis points: 1200 = 12,00%, только разовая от себестоимости. Срок 1–36 месяцев. Поле `sale_price = cost + profit` защищено CHECK. Договорная сумма графика равна цене, сумма будущих платежей без взноса равна остатку по условиям. Реальная задолженность учитывает все проведённые платежи, включая отмены.

## Правила записи

Authenticated не получает INSERT/UPDATE/DELETE на финансовые таблицы. `app_command` — SECURITY DEFINER с фиксированным search_path; перед записью проверяет auth.uid, членство и роль. Tenant определяется по membership, не по телу HTTP-запроса. Все команды организации сериализуются блокировкой строки организации; ключ операции дополнительно UNIQUE. Это сознательный выбор MVP: безопасность и простота при небольшом числе сотрудников. Для масштабирования заменить блокировку организации на упорядоченные блокировки отдельных агрегатов без ослабления идемпотентности.

Одна учётная запись относится к одной организации в MVP (`unique(user_id)`). Несколько независимых компаний уже изолируются. Переключение одной учётной записи между несколькими организациями требует отдельного механизма выбора активного tenant и проверок membership.

## Права

| Возможность | Owner | Manager | Cashier | Client | Platform admin без membership |
|---|---|---|---|---|---|
| Клиенты, заявки, закупки | Да | Да | Нет | Только своя карточка | Нет |
| Оформление/передача договора | Да | Да | Нет | Нет | Нет |
| Чтение договоров и PDF | Да | Да | Да | Только свои | Нет |
| Поступления | Да | Нет | Да | Чтение своих | Нет |
| Отмена платежа | Да | Нет | Нет | Нет | Нет |
| Кассовые операции | Да | Нет | Да | Нет | Нет |
| Тарифы/ручная прибыль | Да | Нет | Нет | Нет | Нет |
| Журнал аудита | Да | Нет | Нет | Нет | Нет |
| Метаданные компаний/подписок | Свои | Своя компания | Своя компания | Своя компания | Все, без клиентских данных |

Подробная история изменения статусов хранится в audit_logs. В клиентский кабинет не попадают заявки, закупочные файлы, кассы, тарифные настройки, данные других клиентов.
