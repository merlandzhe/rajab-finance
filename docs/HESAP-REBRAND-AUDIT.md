# HESAP — аудит названия (6 ноября 2026)

## Внешнее название

- Бренд интерфейса, заголовок страниц, PDF: HESAP.
- Новый бот: `@Hesap95bot`. Отображаемое имя, описание, «О боте», аватар и название Mini App задаются в BotFather владельцем бота.
- Новый публичный адрес: `https://hesap-mini-app.vercel.app/mini` — добавлен в существующий Vercel-проект и отвечает HTTP 200.
- Старый публичный адрес пока продолжает использоваться рабочим ботом и `APP_ORIGIN`; не удалять до завершения миграции.
- Production в данный момент содержит старый `TELEGRAM_MINI_APP_BOT_USERNAME` и соответствующий токен. **Нельзя изменить только имя, пока новый токен не установлен и не протестирован.**

## Уведомления

- Функции создания сообщений в Supabase обновлены: тексты `RAJAB FINANCE` заменены на HESAP.
- Новые уведомления предпринимателям больше не содержат ссылку на устаревший домен.
- Исторически отправленные уведомления сохраняются как архив; неподтверждённые / ожидающие доставки сообщения приведены к HESAP.
- Исходный SQL для нового развёртывания: `supabase/migrations/20261106134500_hesap_notification_brand.sql`.

## Системные идентификаторы — сохранять до миграции

- `rajab-buyer` в вычислении внутреннего email Telegram — криптографический namespace для однозначного поиска существующих аккаунтов; простая замена создаст дубликаты покупателей.
- `rajab_telegram_buyer` и `rajab_pending_merchant` в Supabase Auth `app_metadata` и SQL-функциях — служебные маркеры авторизации. Не менять без совместимой миграции и теста.
- Имя репозитория `merlandzhe/rajab-finance` и техническое имя проекта Vercel `rajab-finance-mini` ещё исторические. Публично используется HESAP; переименовать технические имена после завершения миграции URL и Telegram, иначе можно нарушить интеграции / webhook.

## Отдельные данные продавца

В Supabase есть организация с названием «Раджап». Это **сведения о продавце**, а не название платформы; могут использоваться в сделках или документах. Не подменять продавца названием платформы HESAP без подтверждения корректного наименования организации, особенно в уже подписанных договорах.

## Блокер переключения

Владелец должен в BotFather назначить название `HESAP | Рассрочка`, описание, фото и адрес Mini App. Новый токен указать только в Vercel Production, не отправлять в чат. Затем одновременно настроить Production `TELEGRAM_MINI_APP_BOT_USERNAME=Hesap95bot`, `APP_ORIGIN=https://hesap-mini-app.vercel.app`, webhook и проверить вход/платежи/уведомления. До этого старого бота и адрес не отключать.
